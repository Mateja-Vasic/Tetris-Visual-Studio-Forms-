Tetris Application made in Visual Studio Forms

!Flasing Lights Warning!
Due to the nature of the control I used for displaying the game it flashes every update (more on it later).

Made for a local school hosted game jam and achieved first place.
Visual Studio Forms is not made for making games, but in the competition rules it was requiered to be used as a template for the game. While building this project, I deliberately experimented with Object-Oriented Programming (OOP) principles to better understand the practical applications of classes and objects.
".Net Frameworks Drawing Canvas" was used for displaying the game in real time, there was no better control that would let me visually display a game like Tetris at the time.
Almost every component of the game is in its own class and the individual Blocks all have a parent abstract class that they derive from and that gave me a lot of useful experience with OOP.

Important Features: Hold a piece, Preview next piece, Hard-drop, Soft-drop.
